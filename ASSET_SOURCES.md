# Asset sources

External commercial product and brand assets could not be downloaded because all outbound HTTP requests were rejected by the environment proxy with `403 Forbidden`. To preserve the strict no-fabrication rule, the rendered fallback does **not** draw, reconstruct, or impersonate any product or company logo. The design reserves image regions and the source tree contains the required drop-in asset directories.

No external images or logos are included in this build. No source URLs are fabricated.
